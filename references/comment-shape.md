# 意见的形状

第 3 步用。最终交给会议的意见形状是定死的，第 4 步改稿时也不许被改掉。

## 三条硬约束

1. **3–4 条**，不多写。条数少不影响质量，含糊才影响（见 survey/00 第二部分）。
2. **每条一句话。**
3. **每条的结构是位置加问题加建议动作。** 位置要具体到页码、节号、图号、表里的某个数字或公式编号。

第 3 条是整组约束里最硬的一条，有实证支撑。ICLR 2025 给审稿人做反馈的实验里，修改后的评审平均加长约 80 词，盲审判定更有信息量更具体；AAAI-26 的问卷里作者最欢迎的是可执行的修改指引；ARR 的措辞是别写「X 不清楚」，要写清楚到底缺什么信息（见 survey/01 §1.1、survey/02 §2.1）。

位置还有第二重作用。五种主流检测器都会把「人写加 LLM 润色」的评审误判成 AI 生成，光改文风不足以自证清白；带页码、公式编号、表里具体数字的句子只有真读过论文的人写得出来（见 survey/01 §3 第 4 步、§5.4）。

## 这个形状从哪来

AlexWortega 的 `prompts/reviewer.md` 里的 major concern 四段式：Issue（一句话说清问题）、Where（章节图表位置，缺失就写 absent）、Why it matters（如何影响主张）、What would address it（作者能做的具体修改）。把四段压成一句，剩下的正好是位置加问题加建议动作，而且天然避开 AI 味的老三样，总分总、加粗小标题、排比（见 survey/02 §2.4）。

压的时候 Why it matters 通常并进问题那半句，不单独成分句。

## 两条会议级约束

**ARR：低 soundness 分必须有对应的具体缺陷支撑**，否则算「你的评审没有忠实解释你的推荐」。ARR 明确列举了差评审的特征：含糊、讽刺挖苦、低分无依据、无视作者澄清（见 survey/02 §2.1）。所以打低分时，那 3–4 条里必须有一条直接指向导致低分的缺陷，不能靠一堆小毛病堆出一个低分。

**CVPR：声称存在 prior work 必须给出具体文献。** 给不出就不许写「缺乏新意」。CVPR 的不负责任评审四判据里，「对方法或结果有可证伪的事实错误」与「通用到可套任何投稿」各占一条（见 survey/04 §2.3）。论文卡第 4 层的 `nearest_prior` 栏就是为这条准备的，那一栏是空的就不要写新颖性方面的意见。

## 正例

```
1. 表 2 第 3 行的 BERT 基线是从原文抄来的（p7 §4.1），而本文换了分词器，请补一次自跑结果或说明两者可比。
2. 图 4 的阴影带没有说明是标准差还是标准误（p9 Fig4），请在图注里写明并给出 seed 数。
3. 式 (7) 假设噪声独立同分布（p4 Eq7），但 §5.2 的真实数据集按时间切分，请说明该假设在此处是否仍成立。
4. 摘要报的 12.3% 提升在正文里找不到对应数字（p1 与 p8 Tab3 最大差值为 9.1%），请对齐两处口径。
```

四条各自带着不同类型的锚点：表里某一行、某张图、某个公式、摘要与表的数字对不上。每条都给了作者能做的具体动作。

## 反例

```
1. 实验不够充分，建议补充更多实验。
```
没有位置，没有具体缺什么。ARR 点名的「含糊」就是这一类，作者拿到它不知道该动哪里。

```
2. **实验设计**：本文的实验设计存在明显不足，基线选择不够全面。
```
加粗小标题加冒号，是 AI 味最典型的格式特征（见 survey/02 §4）。而且「不够全面」仍然没有位置。

```
3. 论文的方法部分写得很清楚 —— 但实验部分明显仓促。
```
破折号。这条同时还犯了先扬后抑的路标句毛病，真正的信息只有「实验仓促」四个字，仍然没有位置。

```
4. 总体而言，本文在问题设定上有新意，在方法上有改进，在实验上有欠缺，建议作者进一步完善。
```
「总体而言」收尾加三项排比，一条里三个分句结构完全对仗。整句里没有任何一个页码、图号或数字，换成任何一篇投稿都成立，正是 CVPR 说的「通用到可套任何投稿」。

## 自查

写完之后逐条问一遍：

- 这条句子里有没有页码、节号、图号、表号、公式号或某个具体数字。
- 去掉这个具体位置之后，这句话还能不能原样套到另一篇投稿上。能套就是废话。
- 作者读完知不知道要动哪里、动成什么样。
- 如果打了低分，这 3–4 条里有没有一条直接支撑那个低分。
- 如果写了「缺乏新意」，有没有给出具体的 prior work 文献。
