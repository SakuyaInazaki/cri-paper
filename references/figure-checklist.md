## 通用四问

- [ ] 图内文字有没有乱码或生造词 ｜来源 survey/01 §4.3
- [ ] 图注和图的内容对得上吗 ｜来源 survey/01 §4.3
- [ ] 曲线是不是过于平滑，缺少真实数据该有的噪声 ｜来源 survey/01 §4.3
- [ ] 有没有误差棒或任何变异性报告 ｜来源 survey/01 §4.3

前置规则

- [ ] 图看的是原 PDF 页而不是文本管线的输出 ｜来源 规格 §4
- [ ] panel 数 ≥ 4 的图逐 panel 过了一遍，并在第 6 层 `fact` 栏写明看过哪些 panel（复杂多 panel 图正是重复最容易藏身处） ｜来源 Bik
- [ ] 摘要上方的 teaser 图已手工补进骨架（pdffigures2 会主动排除它） ｜来源 规格 §3 第 6 层

## ML 组

- [ ] 坐标轴是否正确标注（单位、量纲、变量名） ｜来源 Keshav pass 2
- [ ] 结果是否带误差棒或其他统计显著性信息，且定义正确 ｜来源 NeurIPS checklist Q7
- [ ] 误差棒语义是否写明：SD 还是 SEM，变异来源是什么（划分、初始化、随机种子），计算方法是否说明，跑了几个 seed，阴影带代表什么 ｜来源 ML Repro
- [ ] 非对称分布是否用了对称误差棒，以至画出越界值（例如负的错误率） ｜来源 survey/04 §5（组内未注出处）
- [ ] 每张图表是否都被正文引用过，caption 是否自足（不读正文也能看懂） ｜来源 proofreading
- [ ] 结果图若无不确定性可视化，作者是否明确给出了理由 ｜来源 proofreading（WARN 级）
- [ ] y 轴是否被截断（轴截断会让读者高估差异，事先被告知仍然生效） ｜来源 可视化研究
- [ ] 是否违反比例墨水原则（阴影面积与其代表的量不成比例） ｜来源 可视化研究
- [ ] 纵横比是否被拉伸以夸大趋势，坐标轴是否被反转，对数轴是否标注清楚 ｜来源 可视化研究
- [ ] 同一量在不同图表间的精度与单位是否一致（百分比、分数、小数混用） ｜来源 arXiVeri

## 生医组

- [ ] 图内是否有重复的区块（同一图内，或跨图、跨 panel） ｜来源 Nature
- [ ] blot 和 gel 是否有 lane 拼接（splicing）的痕迹 ｜来源 Nature
- [ ] 是否标明哪些 panel 是 sample processing 或 loading control ｜来源 Nature
- [ ] 提供的未处理原始扫描件与正文图是否对得上 ｜来源 Nature
- [ ] 亮度、对比度、放大等调整是否作用于整幅图，并对同一图内同类型图像等同施加；是否避免了阈值操作、信号范围的扩张或压缩、对高信号的改动 ｜来源 Nature
- [ ] 伪彩与非线性调整（如 gamma）是否明确披露，处理软件与增强技术是否写进 methods ｜来源 Nature
- [ ] 生命科学论文的 gel、western blot 未处理原图是否随终稿提交 ｜来源 Nature
- [ ] 重复属于哪一类：简单重复（可能是诚实错误）、带重叠或旋转或拉伸的重复以及同图内元素重复（明确的数据操纵）、splicing（两张图拼成一张） ｜来源 Bik
- [ ] 可疑图是否下载下来用 Preview 调过颜色和亮度再看一遍（初筛不需要任何软件） ｜来源 Bik
